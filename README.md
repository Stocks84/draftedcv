# DraftedCV

This is the **DraftedCV template repo**. It is published with GitHub Pages at https://stocks84.github.io/draftedcv/.

## Master template

`daniel-hartwell/` is the master template: a fictional demo CV (two-page A4 layout, headshot, QR code at the bottom of page 2 linking to its live page).

- Live demo: https://stocks84.github.io/draftedcv/daniel-hartwell/

## New client workflow

1. Copy `daniel-hartwell/` to a new folder named after the client, lowercase and hyphenated (e.g. `jane-smith/`).
2. Swap in the client's details in `index.html` and replace `headshot.jpg`.
3. Regenerate `qr-code.png` for `https://stocks84.github.io/draftedcv/<folder>/` (black on white, error correction H, 4-module quiet zone, 400×400 PNG).

## Rules

- **Never commit real client data to this repo.** Demo / template content only.
- All content here is fictional. No real names, employers or contact details.
